## Inclusion Rules

Included repositories are public GitHub results whose names or descriptions match at least one of:

- Codex / GPT-5.6 / Claude Code / Cursor jailbreak or pojia
- LLM jailbreak, jailbreak benchmark, red-team prompt testing
- Prompt injection attack, benchmark, taxonomy, or defense
- AI agent security guardrail, scanner, firewall, or MCP security
- Curated lists relevant to the above

Excluded or de-prioritized:

- Game "armor break" results unrelated to AI
- General AI projects where "jailbreak" or "prompt injection" is incidental
- Repositories with no clear relation in name or description

## Maintenance Notes

GitHub search rankings and star counts can change daily. Refresh before making decisions based on popularity.

Recommended refresh cadence:

1. Re-run the searches listed in [docs/search-method.md](docs/search-method.md).
2. De-duplicate by `owner/repo`.
3. Re-sort each category by stars descending.
4. Keep entries link-only and avoid copying operational payloads.
